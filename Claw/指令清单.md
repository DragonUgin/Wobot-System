# Claw 指令清单

> 所有指令在工作群发送，仅游戏运行中生效。猎人 / 任务点 NPC 身份 = 工作群成员（去名单化），系统只验证业务指令格式。

## 占位符图例

| 字母 | 含义 |
|---|---|
| `X` | 组号（数字）；任务点完成/接收里 = 线索编号 |
| `Y` | 猎人名（静止卡/护盾卡）；任务点完成/接收里 = 露水编号（完成已砍掉送出，仅接收有效） |
| `Z` | 金露水 / 护盾卡 / 静止卡 数量 |
| `N` | 任务点编号 / 线索编号（静止卡送出线索） |
| `M` | 露水编号（静止卡格式保留，但送出已砍，仅作提示） |
| `XXX` | 玩家名 / 猎人名 / 地点（多字符占位） |

> 实际发送时：编号位填数字，数量位填数字或「无」。

## 一、猎人指令

### 1. 淘汰（无道具）
```
X组XXX被XXX淘汰
```
- 示例：`1组张三被李四淘汰`
- 效果：淘汰玩家；猎人冷却 20 秒（狂欢 40 秒）；全局免疫期不可用。

### 2. 淘汰（带道具护送）
```
X组XXX被XXX在XXX淘汰 召唤机动人员
```
- 示例：`1组张三被李四在学校淘汰 召唤机动人员`
- 效果：淘汰并记录地点，通知后台群机动护送；冷却同上。

### 3. 静止卡（唯一可让玩家获得线索的卡；露水送出已砍）
```
猎人Y被使用静止卡 [获得线索N] [获得露水M]
```
- 示例：`猎人李四被使用静止卡 获得线索2 获得露水35`（露水35 送出已停用，仅线索2 生效；猎人露水现与线索同号，如示例姓名=35）
- 效果：猎人送出线索给玩家（消耗其持有），置「已发现未收集」；冷却 180 秒。露水送出功能已砍掉，指令含「获得露水M」仅告警提示、不录入系统。
- 说明：「获得线索N」「获得露水M」各自独立子句，可只写一个、可同条出现、顺序任意。「获得线索N」仍生效（消耗猎人持有线索）；「获得露水M」已砍，Bot 提示「送出功能已停用」。猎人露水只能经网页/接收入库，不再由指令送出。

### 4. 护盾卡
```
猎人Y被使用护盾卡
```
- 示例：`猎人李四被使用护盾卡`
- 效果：确认使用护盾卡；冷却 20 秒。**不再支持获得线索**。

### 注意事项
- 淘汰冷却按发送者 QQ 记录；静止卡 / 护盾卡冷却按猎人名记录。
- 全局任务免疫期间（任意任务点完成后 15 秒）所有淘汰指令被拦截。
- 猎人持有物（线索 / 露水）只能由管理员网页导入 / 分配，游戏指令只消耗不新增。
- 已废弃指令：`线索N 已收集`（改由静止卡 / 任务点完成触发）。

## 二、任务点 NPC 指令

### 1. 任务点完成（送出道具）
```
任务点N 完成 线索X 露水Y 金露水Z 护盾卡Z 静止卡Z
```
- 示例：`任务点3 完成 线索5 露水2 金露水无 护盾卡无 静止卡无`
- 效果：送出道具给玩家；触发全局免疫 15 秒（全体玩家不可被淘汰）。
- 说明：`露水Y` 的 **Y 是露水编号**（非数量）。★任务点完成已砍掉送出露水（指令格式保留，系统忽略 Y），露水仅可经「接收」指令或网页端编辑/入库。

### 2. 任务点接收（入库道具）
```
任务点N 接收 线索X 露水Y 金露水Z 护盾卡Z 静止卡Z
```
- 示例：`任务点3 接收 线索无 露水4 金露水1 护盾卡2 静止卡无`
- 效果：道具入库；不触发免疫。
- 说明：`露水Y` 的 **Y 是露水编号**（非数量），系统按编号精确入库该张散落露水（重置为「未收集」并收回任务点池）。

### 注意事项
- 指令须精确匹配：关键字「完成 / 接收 / 线索 / 露水 / 金露水 / 护盾卡 / 静止卡」必须原样，多余空格可容忍。
- 编号位填数字，数量位填数字或「无」。
- 任务点完成后 15 秒内全体玩家免疫淘汰（全局任务免疫）。
- 任务点 NPC 名单已去名单化，靠工作群成员资格保证身份，系统只验证业务指令格式。
